# 2027 Summit Stopwatch

2027년 신년 목표를 "정상 도전"으로 시각화한 스톱워치예요. 목표를 고르고 시간을 재면 주간 목표 대비 진행률만큼 등반 마커가 산을 올라가요.

## 사용법

`stopwatch.html`을 브라우저에서 열면 돼요. 설치나 빌드는 필요 없어요.

- 목표(운동·독서·외국어·명상)를 고르고 **출발**을 누르세요.
- **잠깐 쉬기**로 멈추고, **기록 저장**으로 이번 주 누적에 더해요.
- 25·50·75% 캠프를 지나 100%가 되면 정상에 도달해요.
- 기록은 브라우저 localStorage에 주 단위(월요일 시작)로 저장돼요.

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 출발 / 쉬기 |
| `Enter` | 기록 저장 |
| `1`–`4` | 목표 선택 |

## 목표 바꾸기

`stopwatch.html`의 `GOALS` 배열에서 이름, 아이콘, 주간 목표 시간(분)을 수정하세요.
